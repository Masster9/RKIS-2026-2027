# TodoListApp

Консольное приложение на C# (.NET 10) — практические задания по курсу РКИС.

Работу выполнили: Киснер и Маркелов, группа 3831.

## Запуск

```
cd TodoListApp
dotnet run --project TodoListApp
```

## Занятие 2 — Введение в C# и .NET

- создан консольный проект `TodoListApp`;
- добавлен `.gitignore` (папки `bin`, `obj`, `.vs`);
- программа выводит, кто выполнил работу;
- программа спрашивает имя, фамилию и год рождения, переводит год в число,
  вычисляет возраст и выводит сообщение:
  `Добавлен пользователь <Имя> <Фамилия>, возраст - <возраст>`.

## Занятие 3 — Ветвления и циклы

После ввода данных пользователя программа работает в бесконечном цикле и ждёт команды:

| Команда | Что делает |
|---|---|
| `help` | выводит список команд с кратким описанием |
| `profile` | выводит данные пользователя: `<Имя> <Фамилия>, <Год рождения>` |
| `add "текст задачи"` | добавляет новую задачу (текст выделяется через `String.Split`) |
| `view` | выводит все задачи (только непустые элементы массива) |
| `exit` | завершает цикл и программу |

Задачи хранятся в массиве строк `todos` начальной длины 2. Если места не хватает,
создаётся новый массив в 2 раза длиннее, старые задачи переписываются в него циклом,
и `todos` начинает ссылаться на новый массив.
